# Sunday Style Market

Starter storefront website for Sunday Style Market.

## Files
- `index.html` — homepage and shop layout
- `style.css` — website styling
- `script.js` — basic shopping cart behavior

## How to open
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Use the Live Server extension, or double-click `index.html` to preview in a browser.
